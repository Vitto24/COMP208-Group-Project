Stage 1 Scrape Courses
scrape_course.py

Extracts module codes organised by year and semester from course pages.

  • Parses course page HTML
  • Finds module codes per year
  • Separates compulsory vs optional
  • Handles varied year formats (1, 2, S1, FP)

Stage 2 Scrape Module Details
scrape_tulip.py

Fetches detailed module information from the TULIP database for each module code.

  • Name, credits, department
  • Lecturer, semester, level
  • Assessment breakdown (exam/CW %)
  • Prerequisites & description
  • Skips already-scraped modules

Stage 3 Import to Database
import_to_db.py

Loads JSON files into Django models, creating courses, modules, and linking them.

  • Creates/updates Module records
  • Creates/updates Course records
  • Links via ModuleCourse (year, compulsory)
  • Sets year weights for degree calc
  • Supports dry-run mode
