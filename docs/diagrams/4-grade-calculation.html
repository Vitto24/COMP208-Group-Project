Grade Calculation Flow

From individual assignment scores to degree classification projection

1
Individual Assignment Scores
Per assignment
for each assignment in module:
  score = grade.score // 0–100
  weight = assignment.weight // e.g. 40%

Each assignment has a percentage weight within its module (e.g. 60% exam, 40% coursework). Ungraded assignments are excluded from calculations.

Example: COMP208
Coursework (40%) 72
Final Exam (60%) 68
weighted sum
2
Module Grade
Per module
module_grade = Σ(score × weight / 100)

// weighted average of all graded assignments

Only graded assignments contribute. The sum of weights across all assignments in a module should total 100%.

Example: COMP208
72 × 0.40 28.8
68 × 0.60 40.8
Module Grade 69.6%
credit-weighted average
3
Semester Average
Per semester
semester_avg = Σ(module_grade × credits)
                / Σ(credits)

// credit-weighted, not simple mean

Averages are weighted by module credits (typically 15 credits each). A 30-credit module counts twice as much as a 15-credit one.

Example: Semester 2
COMP208 (15cr) — 69.6 1044.0
COMP212 (15cr) — 74.2 1113.0
COMP219 (15cr) — 65.0 975.0
COMP222 (15cr) — 71.8 1077.0
Semester Avg (60cr) 70.2%
credit-weighted average
4
Year Average
Per academic year
year_avg = Σ(module_grade × credits)
           / Σ(credits)

// all modules in current year
// (both semesters combined)

Combines both semesters in the current year of study. Uses the same credit-weighted formula across all enrolled modules for that year.

Example: Year 2
Semester 1 (60cr) 67.5
Semester 2 (60cr) 70.2
Year Average (120cr) 68.9%
